Place extension icons here:
- icon16.png
- icon48.png
- icon128.png

These are optional for "Load unpacked" / "Load Temporary Add-on" development. To use
them, add an `"icons"` block to manifest.json and a `"default_icon"` under `"action"`.
Any 128x128 (or 16/48/128) PNG works; the FACEIT logo is appropriate.
